# EA Feedback App

this is a app for feedback

## how to run

just run it

```
python app.py
```

or maybe use flask run idk

## features

- has forms
- stores stuff
- you can see the data

## dependencies

- flask (should work with any version)
- python (tested on 2.7 and 3.x)

## installation

1. install python
2. install flask
3. run the app

```bash
pip install flask
python app.py
```
